## 📌 Descripción

Este proyecto consiste en un **portal personal profesional de identidad**, desarrollado como una página web que reúne información personal, académica y profesional en un solo sitio.

El portal permite conocer diferentes aspectos de mi perfil, incluyendo mi identidad, portafolio, currículum y una sección adicional con información acerca del proyecto.

---

## 🚀 Tecnologías utilizadas

El proyecto fue desarrollado utilizando tecnologías básicas del desarrollo web:

* 🌐 **HTML5** — Estructura y contenido de las páginas.
* 🎨 **CSS3** — Diseño, estilos y presentación visual.
* ⚡ **JavaScript** — Funcionalidades e interactividad.

---

## 📄 Páginas principales

El sitio está compuesto por las siguientes páginas:

| Archivo           | Descripción                                                 |
| ----------------- | ----------------------------------------------------------- |
| `index.html`      | Página principal del portal.                                |
| `identidad.html`  | Información relacionada con mi identidad y perfil personal. |
| `portafolio.html` | Proyectos y trabajos realizados.                            |
| `cvu.html`        | Currículum vitae y trayectoria académica/profesional.       |
| `acerca.html`     | Información adicional acerca del sitio y su desarrollo.     |
